small voice assistant in Python. It listens through your microphone and replies out loud. If the voice libraries aren't installed, it runs in text mode.
Run
python jarvis.py
Voice mode (optional):
pip install -r requirements.txt
Commands
what time is it / what is the date
search for <anything> opens a Google search
open youtube / google / github / gmail
help, goodbye
Add new commands in the handle() function in jarvis.py.
